# Changelog

## 1.0.0 — 2026-11-17

- First release: text and URL QR codes, styled codes, WiFi, vCard,
  email, phone and SMS payloads, logo embedding, PNG, SVG and
  terminal output, batch generation from CSV and JSON, and a command
  line interface with `generate`, `wifi`, `vcard`, `batch` and
  `info` subcommands.
